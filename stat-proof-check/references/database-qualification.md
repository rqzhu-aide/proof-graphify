# Reviewer identity in v3

Ordinary v3 audits do not require calibration. Record the actual reviewer, independent context and exposure, and use a null qualification ID when no calibration exists.

Preserve genuine prior calibration as optional evidence. Do not invent a qualification or describe uncalibrated review as calibrated. Independence still requires an actual separate examination of the source question.

Use independent-checker.md and the Stage 2 workflow. Historical calibration APIs remain for interpreting older evidence; they are not a preparation checklist for v3.
